域名 / IP 分流

命中规则的目标走直连或 VPN，未命中的走默认动作。
默认走 VPN
命中规则才直连
默认直连
命中规则才走 VPN
规则从上到下依次匹配，命中即按该规则的动作处理：
· domain 域名后缀，如 baidu.com 匹配 www.baidu.com、tieba.baidu.com
· keyword 域名包含关键词，如 google 匹配所有含 google 的域名
· cidr IP 或网段，如 192.168.0.0/16、10.0.0.1
· geosite 按 Geo 站点分类，如 geosite:cn（中国常见网站）、geosite:private（内网/局域网域名）
· geoip 按 Geo IP 归属，如 geoip:cn（中国 IP 段）、geoip:private（私有/保留 IP 段）
动作「直连」表示该目标不经过 VPN 直接访问，「走 VPN」表示强制经过隧道。
